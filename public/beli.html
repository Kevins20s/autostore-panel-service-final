Pertanyaan umum

Berapa lama key aktif?

Sesuai paket yang dipilih (30 atau 90 hari) dihitung sejak key dibuat. Kamu bisa memperpanjang kapan saja dari menu Subscription di panel, sisa harinya tidak hangus.

Kapan key saya muncul?

Kalau pembayaran otomatis aktif, beberapa detik setelah lunas. Kalau memakai QRIS manual, setelah penjual memeriksa mutasi dan mengonfirmasi (biasanya beberapa menit).

Saya sudah bayar tapi key belum muncul

Jangan bayar dua kali. Simpan kode pesananmu, lalu hubungi penjual dengan kode itu. Link pesanan di halaman ini bisa dibuka lagi kapan saja.

Apa yang perlu saya siapkan?

Token dan Client ID bot Discord milikmu, serta database MongoDB (Atlas gratis cukup). Panduan lengkapnya ada di menu Tutorial Setup setelah login.
