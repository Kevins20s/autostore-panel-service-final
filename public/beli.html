Pertanyaan umum

Berapa lama key aktif?

Masa aktif key berjangka dimulai saat login pertama dan mengikuti durasi paket. Perpanjangan lewat menu Langganan menambahkan durasi ke sisa masa aktif. Lisensi lifetime berlaku tanpa perpanjangan.

Kapan key saya muncul?

QRIS otomatis menampilkan key setelah pembayaran terdeteksi. Untuk pembayaran DL atau QRIS manual, key muncul setelah penjual mengonfirmasi pembayaran.

Saya sudah bayar tapi key belum muncul

Jangan bayar dua kali. Simpan kode pesananmu, lalu hubungi penjual dengan kode itu. Link pesanan di halaman ini bisa dibuka lagi kapan saja.

Apa yang perlu saya siapkan?

Untuk bot sendiri, siapkan token, Client ID, dan MongoDB. Bot GevraStore tersedia untuk lisensi yang mendapat akses. Pada mode itu, cukup hubungkan akun Discord dan pilih server yang kamu kelola.
